# perfekt unperfekt by Uschi

German website mockup for a handmade sewing brand.

## Contents
- Responsive product showcase
- Patchwork-heart symbol and matching outlined wordmark
- Product category filters
- Enquiry builder with copy-to-clipboard; no messages are sent

## Preview locally
Run `python3 -m http.server 8000` and open `http://localhost:8000`.

## Deployment
Publish the repository root directory on any static web host. No build step or dependencies.

## Before public launch
The product photos are AI-generated illustrative samples, not photographs of Uschi’s actual products. Replace them with her real product photos and confirm the product copy. Prices, dimensions, availability and contact details have not been supplied. The enquiry feature only prepares a message; it does not send anything.

## Brand
Linen #F7F3EC, sage #768675, dusty rose #C39588, deep green #303C35. Logos are concept designs, not evidence of trademark registration or exclusivity.
